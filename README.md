## Sobre o Projeto

Este repositório faz parte do meu aprendizado em Kotlin. Aqui, exploro conceitos da linguagem e aplico os aprendizados no desenvolvimento de aplicações usando o framework Spring Boot.

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/PedroPaino/Kotlin.git
   ```
2. Certifique-se de ter o Kotlin e o Spring Boot configurados no seu sistema.

## Uso

Execute o seguinte comando para iniciar a aplicação:
```bash
./gradlew bootRun
```
